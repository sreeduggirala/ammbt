# PnL Distribution

## Basic Histogram

```python
import ammbt as amm

fig = amm.plot_pnl_distribution(result)
fig.show()
```

## Add Statistics

```python
import numpy as np

fig = amm.plot_pnl_distribution(result)

pnl = result.metrics['net_pnl']
for p in [10, 50, 90]:
    value = np.percentile(pnl, p)
    fig.add_vline(x=value, line_dash='dash',
                  annotation_text=f'P{p}: ${value:.0f}')

fig.show()
```

## Summary Stats

```python
pnl = result.metrics['net_pnl']

print(f"Mean: ${pnl.mean():.2f}")
print(f"Median: ${pnl.median():.2f}")
print(f"Std: ${pnl.std():.2f}")
print(f"Min: ${pnl.min():.2f}")
print(f"Max: ${pnl.max():.2f}")
print(f"Profitable: {(pnl > 0).sum()}/{len(pnl)} ({(pnl > 0).mean():.1%})")
```
