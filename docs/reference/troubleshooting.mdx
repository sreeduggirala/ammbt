# Troubleshooting

## Installation Issues

### pip install fails

```bash
# Update pip
pip install --upgrade pip

# Try with --no-cache
pip install --no-cache-dir ammbt
```

### Numba installation problems

```bash
# Install LLVM dependencies
# macOS
brew install llvm

# Ubuntu
sudo apt install llvm

# Then reinstall
pip install --upgrade numba
```

## Performance Issues

### Slow first run

Numba compiles on first use. Enable caching:

```python
from ammbt.utils import Config
Config.set("numba.cache", True)
```

### High memory usage

Process in batches:

```python

    results = []
```

## Data Issues

### Price column has wrong values

Check decimal adjustments:

```python
# USDC has 6 decimals, ETH has 18
swaps['amount0'] /= 10**18  # ETH
swaps['amount1'] /= 10**6   # USDC
swaps['price'] = abs(swaps['amount1']) / abs(swaps['amount0'])
```

### Timestamps not monotonic

Sort and deduplicate:

```python
swaps = swaps.sort_values('timestamp').drop_duplicates('timestamp')
```

## Results Issues

### All strategies show same results

Check that strategy parameters actually vary:

```python
print(result.strategy_params.nunique())
```

### Unexpected negative returns

Check for:
1. Impermanent loss exceeding fees
2. High gas costs from frequent rebalancing
3. Starting price vs ending price

```python
print(f"Price change: {swaps['price'].iloc[-1]/swaps['price'].iloc[0] - 1:.2%}")
```
