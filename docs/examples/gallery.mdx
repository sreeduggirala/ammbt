## Quick Start Example

```python
import ammbt as amm

# 1. Generate data
swaps = amm.generate_swaps(n_swaps=10000, price_volatility=0.02, seed=42)

# 2. Define strategies
strategies = {
    'initial_capital': [10000, 25000, 50000],
    'tick_lower': [-200, -400],
    'tick_upper': [200, 400],
    'rebalance_threshold': [0.0, 0.05, 0.10],
}

# 3. Run backtest
bt = amm.LPBacktester(amm_type='v3', fee_tier=3000)
result = bt.run(swaps, strategies)

# 4. Analyze
print("Top 5 Strategies:")
print(result.summary().head())

# 5. Visualize
fig = amm.plot_efficient_frontier(result)
fig.show()
```

## Running Examples

All examples can be run as Python scripts or Jupyter notebooks:

```bash
# Clone repository
git clone https://github.com/your-org/ammbt.git
cd ammbt/examples

# Run script
python uniswap_v3/concentrated_liquidity.py

# Or open notebook
jupyter lab uniswap_v3/concentrated_liquidity.ipynb
```
