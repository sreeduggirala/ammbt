# V2 Rebalancing Strategies

Compare passive vs active rebalancing strategies.

```python
import ammbt as amm
import pandas as pd

# Generate data
swaps = amm.generate_swaps(n_swaps=20000, price_volatility=0.03, seed=42)

# Define strategies
strategies = {
    'initial_capital': [25000],
    'rebalance_threshold': [0.0, 0.03, 0.05, 0.10, 0.15, 0.20],
    'rebalance_frequency': [0],
}

# Run backtest
bt = amm.LPBacktester(amm_type='v2')
result = bt.run(swaps, strategies)

# Compare results
comparison = result.metrics[[
    'rebalance_threshold', 'net_pnl', 'total_fees_earned',
    'impermanent_loss', 'num_rebalances', 'gas_spent'
]]
print(comparison)

# Visualize
import plotly.express as px
fig = px.bar(
    comparison,
    x='rebalance_threshold',
    y='net_pnl',
    title='Net PnL by Rebalance Threshold'
)
fig.show()
```
