## Quick Reference

### Main Imports

```python
import ammbt as amm

# Core
amm.LPBacktester

# Data generation
amm.generate_swaps
amm.generate_price_path

# Plotting
amm.plot_performance
amm.plot_metrics_heatmap
amm.plot_efficient_frontier
amm.plot_pnl_distribution
```

### Utility Imports

```python
from ammbt.utils import (
    # Config
    Config,

    # V3 utilities
    tick_to_price,
    price_to_tick,
    get_tick_spacing,
    generate_tick_ranges,
    create_v3_strategy_grid,

    # DLMM utilities
    bin_id_to_price,
    price_to_bin_id,
    generate_bin_ranges,
    create_dlmm_strategy_grid,
    SHAPE_SPOT,
    SHAPE_CURVE,
    SHAPE_BID_ASK,
)
```
