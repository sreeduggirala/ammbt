# Tick Conversions

Utilities for converting between V3 ticks and prices.

## Functions

### tick_to_price

Convert tick to price.

```python
def tick_to_price(tick: int) -> float
```

Formula: `price = 1.0001 ** tick`

### price_to_tick

Convert price to nearest tick.

```python
def price_to_tick(price: float) -> int
```

### sqrt_price_to_price

Convert Q96 sqrt price to regular price.

```python
def sqrt_price_to_price(sqrt_price_x96: int) -> float
```

### price_to_sqrt_price

Convert price to Q96 sqrt price.

```python
def price_to_sqrt_price(price: float) -> int
```

### get_tick_spacing

Get tick spacing for fee tier.

```python
def get_tick_spacing(fee_tier: int) -> int
```

| Fee Tier | Spacing |
|----------|---------|
| 500 | 10 |
| 3000 | 60 |
| 10000 | 200 |

### round_tick_to_spacing

Round tick to valid spacing.

```python
def round_tick_to_spacing(tick: int, spacing: int) -> int
```

## Examples

```python
from ammbt.utils import tick_to_price, price_to_tick

# Tick to price
price = tick_to_price(1000)  # ~1.1052

# Price to tick
tick = price_to_tick(2000.0)  # ~69315

# Valid tick for 0.3% tier
from ammbt.utils import round_tick_to_spacing
valid_tick = round_tick_to_spacing(123, 60)  # 120
```
