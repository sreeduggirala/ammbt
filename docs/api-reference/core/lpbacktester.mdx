# LPBacktester

The main class for running LP strategy backtests.

## Constructor

```python
class LPBacktester:
    def __init__(
        self,
        amm_type: str = 'v2',
        **amm_params
    )
```

### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `amm_type` | str | 'v2' | AMM type: 'v2', 'v3', or 'dlmm' |
| `**amm_params` | dict | - | AMM-specific parameters |

## Methods

### run()

Run backtest with given swap data and strategies.

```python
def run(
    self,
    swaps: pd.DataFrame,
    strategies: Union[Dict[str, List], pd.DataFrame],
) -> BacktestResult
```

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `swaps` | DataFrame | Swap events with amount0, amount1, price, timestamp |
| `strategies` | dict or DataFrame | Strategy parameters to test |

#### Returns

`BacktestResult` - Container with metrics, positions, and analysis methods.

#### Example

```python
import ammbt as amm

# Create backtester
bt = amm.LPBacktester(amm_type='v3', fee_tier=3000)

# Generate data
swaps = amm.generate_swaps(n_swaps=10000, seed=42)

# Define strategies
strategies = {
    'initial_capital': [10000, 25000],
    'tick_lower': [-200, -400],
    'tick_upper': [200, 400],
    'rebalance_threshold': [0.0, 0.05],
}

# Run backtest
result = bt.run(swaps, strategies)

# Access results
print(result.summary())
```

## Strategy Parameters

### V2 Strategies

```python
strategies = {
    'initial_capital': [10000],       # Capital to provide
    'rebalance_threshold': [0.05],    # Price deviation trigger
    'rebalance_frequency': [100],     # Min swaps between rebalances
}
```

### V3 Strategies

```python
strategies = {
    'initial_capital': [10000],
    'tick_lower': [-200],             # Lower tick bound
    'tick_upper': [200],              # Upper tick bound
    'rebalance_threshold': [0.05],
    'rebalance_frequency': [100],
}
```

### DLMM Strategies

```python
strategies = {

}
```
