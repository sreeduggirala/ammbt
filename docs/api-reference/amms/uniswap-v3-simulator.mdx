# UniswapV3Simulator

Simulates Uniswap V3 concentrated liquidity AMM behavior.

## Constructor

```python
UniswapV3Simulator(
    initial_price: float = 1.0,
    initial_liquidity: float = 1_000_000_000,
    fee_tier: int = 3000,
)
```

### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `initial_price` | float | 1.0 | Starting price |
| `initial_liquidity` | float | 1e9 | Pool liquidity |
| `fee_tier` | int | 3000 | Fee in bps (500, 3000, 10000) |

## Fee Tiers

| Tier | Fee | Tick Spacing |
|------|-----|--------------|
| 500 | 0.05% | 10 |
| 3000 | 0.30% | 60 |
| 10000 | 1.00% | 200 |
