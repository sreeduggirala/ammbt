# Your First Backtest

This guide provides a comprehensive walkthrough of ammBT's backtesting workflow, explaining each component in detail. By the end, you'll understand how the engine works internally and be able to customize every aspect of your backtests.

## Understanding the Components

A complete backtest involves four main components:

<Steps>
  <Step title="Swap Data">
    Historical or synthetic trading activity in the pool
  </Step>
  <Step title="Strategies">
    Parameters defining your LP position(s)
  </Step>
  <Step title="AMM Simulator">
    The protocol-specific logic (V2, V3, or DLMM)
  </Step>
  <Step title="Results">
    Metrics, position history, and visualizations
  </Step>
</Steps>

## Part 1: Swap Data

Swap data represents the trading activity in an AMM pool. Each row is a single swap event.

### Required Columns

| Column | Type | Description |
|--------|------|-------------|
| `amount0` | float | Token0 amount (positive = into pool) |
| `amount1` | float | Token1 amount (positive = into pool) |
| `price` | float | Price after the swap (token1/token0) |
| `timestamp` | int | Unix timestamp |

### Swap Direction Convention

```python
# Buy: Trader swaps token0 for token1
# amount0 > 0 (token0 into pool)
# amount1 < 0 (token1 out of pool)

# Sell: Trader swaps token1 for token0
# amount0 < 0 (token0 out of pool)
# amount1 > 0 (token1 into pool)
```

### Generating Synthetic Data

```python
import ammbt as amm

swaps = amm.generate_swaps(
    n_swaps=10000,           # Number of swap events
    initial_price=1.0,       # Starting price
    base_volume=1000.0,      # Average swap size
    volume_volatility=0.5,   # Volume variation
    buy_sell_ratio=0.5,      # 50% buys, 50% sells
    price_volatility=0.02,   # Daily price volatility
    price_model='gbm',       # Geometric Brownian Motion
    time_between_swaps=15,   # Average seconds between swaps
    seed=42
)
```

<Accordion title="Available price models">

**Geometric Brownian Motion (GBM)** - Default
```python
swaps = amm.generate_swaps(price_model='gbm', drift=0.0)
```
Standard model for asset prices. Good for general testing.

**Jump-Diffusion**
```python
swaps = amm.generate_swaps(
    price_model='jump',
    jump_intensity=0.1,    # Jumps per time step
    jump_mean=0.0,         # Average jump size
    jump_std=0.05          # Jump size volatility
)
```
Adds sudden price jumps. Good for testing during volatile periods.

**Ornstein-Uhlenbeck (Mean-Reverting)**
```python
swaps = amm.generate_swaps(
    price_model='ou',
    mean_reversion_speed=0.1,
    long_term_mean=1.0
)
```
Prices revert to a mean. Good for stable pairs (e.g., stablecoin pools).

</Accordion>

### Inspecting Your Data

```python
print(f"Swap count: {len(swaps)}")
print(f"Price range: {swaps['price'].min():.4f} - {swaps['price'].max():.4f}")
print(f"Total volume: ${swaps['volume'].sum():,.0f}")

```

## Part 2: Defining Strategies

Strategies define how your LP positions behave. Different AMM types require different parameters.

### Strategy as Dictionary

The simplest way to define strategies is with a dictionary of lists:

```python
strategies = {
    'initial_capital': [10000, 25000, 50000],
    'rebalance_threshold': [0.0, 0.05, 0.10],
    'rebalance_frequency': [0, 100, 500],
}
```

ammBT creates every combination (Cartesian product):
- 3 × 3 × 3 = **27 strategies**

### Strategy as DataFrame

For more control, use a DataFrame:

```python
import pandas as pd

strategies = pd.DataFrame({
    'initial_capital': [10000, 25000, 50000, 10000],
    'rebalance_threshold': [0.05, 0.05, 0.05, 0.10],
    'rebalance_frequency': [100, 100, 100, 200],
})
```

This tests exactly **4 strategies** (rows), not a Cartesian product.

### Strategy Parameters by AMM Type

<Tabs>
  <Tab title="Uniswap V2">
    ```python
    strategies = {
        'initial_capital': [10000],       # USD value to provide
        'rebalance_threshold': [0.05],    # Rebalance when price changes 5%
        'rebalance_frequency': [100],     # Min 100 swaps between rebalances
    }
    ```

    | Parameter | Type | Description |
    |-----------|------|-------------|
    | `initial_capital` | float | Capital to provide as liquidity |
    | `rebalance_threshold` | float | Price deviation to trigger rebalance (0 = never) |
    | `rebalance_frequency` | int | Minimum swaps between rebalances (0 = disabled) |
  </Tab>

  <Tab title="Uniswap V3">
    ```python
    strategies = {
        'initial_capital': [10000],
        'tick_lower': [-200],             # Lower tick bound
        'tick_upper': [200],              # Upper tick bound
        'rebalance_threshold': [0.05],
        'rebalance_frequency': [100],
    }
    ```

    | Parameter | Type | Description |
    |-----------|------|-------------|
    | `initial_capital` | float | Capital to provide |
    | `tick_lower` | int | Lower tick boundary |
    | `tick_upper` | int | Upper tick boundary |
    | `rebalance_threshold` | float | Price deviation trigger |
    | `rebalance_frequency` | int | Minimum swaps between rebalances |

    <Tip>
    Use `generate_tick_ranges()` to create tick ranges based on percentage widths.
    </Tip>
  </Tab>

  <Tab title="Meteora DLMM">
    ```python
    strategies = {
        'initial_capital': [10000],
        'bin_lower': [-40],               # Lower bin bound
        'bin_upper': [40],                # Upper bin bound
        'liquidity_shape': [0],           # 0=Spot, 1=Curve, 2=Bid-Ask
        'rebalance_threshold': [0.05],
        'rebalance_frequency': [100],
    }
    ```

    | Parameter | Type | Description |
    |-----------|------|-------------|
    | `initial_capital` | float | Capital to provide |
    | `bin_lower` | int | Lower bin boundary |
    | `bin_upper` | int | Upper bin boundary |
    | `liquidity_shape` | int | Distribution shape (0, 1, or 2) |
    | `rebalance_threshold` | float | Price deviation trigger |
    | `rebalance_frequency` | int | Minimum swaps between rebalances |
  </Tab>
</Tabs>

### Rebalancing Logic

Rebalancing occurs when either condition is met:

1. **Threshold trigger**: Price has moved by `rebalance_threshold` from position entry
2. **Frequency trigger**: At least `rebalance_frequency` swaps since last rebalance

Set either to `0` to disable that trigger.

```python
# Never rebalance
strategies = {'rebalance_threshold': [0.0], 'rebalance_frequency': [0]}

# Rebalance on 10% price move only
strategies = {'rebalance_threshold': [0.10], 'rebalance_frequency': [0]}

# Rebalance every 500 swaps minimum
strategies = {'rebalance_threshold': [0.0], 'rebalance_frequency': [500]}

# Rebalance on 5% move OR after 200 swaps
strategies = {'rebalance_threshold': [0.05], 'rebalance_frequency': [200]}
```

## Part 3: Running the Backtest

### Creating the Backtester

```python
# Uniswap V2
bt = amm.LPBacktester(amm_type='v2')

# Uniswap V3 with fee tier
bt = amm.LPBacktester(
    amm_type='v3',
    initial_price=swaps['price'].iloc[0],
    fee_tier=3000,  # 0.3% fee tier
)

# Meteora DLMM with bin step
bt = amm.LPBacktester(
    amm_type='dlmm',
    initial_price=swaps['price'].iloc[0],
    bin_step=25,  # 0.25% per bin
)
```

### Running Strategies

```python
result = bt.run(swaps, strategies)
```

This single call:
1. Initializes position state for all strategies
2. Processes each swap through the AMM simulator
3. Updates positions, fees, and triggers rebalances
4. Calculates all metrics

## Part 4: Analyzing Results

### The BacktestResult Object

```python
result = bt.run(swaps, strategies)

# Available attributes
result.metrics          # DataFrame of calculated metrics
result.positions        # NumPy array of position states
result.strategy_params  # DataFrame of input parameters
result.metadata         # Pool state and simulation info
```

### Metrics DataFrame

```python
print(result.metrics.columns.tolist())
```

| Metric | Description |
|--------|-------------|
| `net_pnl` | Total profit/loss including fees and IL |
| `total_return_pct` | Return as percentage of initial capital |
| `sharpe` | Risk-adjusted return (assuming risk-free = 0) |
| `max_drawdown_pct` | Maximum peak-to-trough decline |
| `total_fees_earned` | Sum of fee income |
| `impermanent_loss` | Value lost due to price divergence |
| `num_rebalances` | Count of rebalancing events |
| `gas_spent` | Total gas costs in USD |
| `time_in_position` | Percentage of time position was active |

### Summary and Ranking

```python
# Get top strategies by net PnL
summary = result.summary()
print(summary.head(10))
```

### Position History

Track a specific strategy over time:

```python
history = result.get_position_history(strategy_idx=0)

# Columns available
print(history.columns.tolist())
# ['liquidity', 'token0_balance', 'token1_balance',
#  'uncollected_fees_0', 'uncollected_fees_1',
#  'gas_spent', 'is_active', 'num_rebalances']
```

### Calculating Portfolio Value

```python
# Portfolio value at each timestamp
prices = swaps['price'].values
token0 = history['token0_balance'].values
token1 = history['token1_balance'].values
fees0 = history['uncollected_fees_0'].values
fees1 = history['uncollected_fees_1'].values
gas = history['gas_spent'].values

portfolio_value = (token0 + fees0) * prices + (token1 + fees1) - gas
```

### Performance Plot

fig = amm.plot_performance(result, strategy_idx=0, show_reserves=True)

## Complete Example

```python
import ammbt as amm
import pandas as pd

# 1. Generate realistic swap data
swaps = amm.generate_swaps(
    n_swaps=10000,
    initial_price=2000.0,  # ETH price
    price_volatility=0.03,
    base_volume=50000,
    price_model='gbm',
    seed=42
)

# 2. Define comprehensive strategy grid
strategies = {
    'initial_capital': [10000, 25000, 50000, 100000],
    'tick_lower': [-200, -400, -600],
    'tick_upper': [200, 400, 600],
    'rebalance_threshold': [0.0, 0.05, 0.10],
    'rebalance_frequency': [0, 200],
}

# 3. Run backtest
bt = amm.LPBacktester(
    amm_type='v3',
    initial_price=2000.0,
    fee_tier=3000
)

result = bt.run(swaps, strategies)
print(f"Tested {len(result.metrics)} strategies")

# 4. Analyze results
summary = result.summary()
print("\nTop 5 Strategies:")
print(summary[['initial_capital', 'tick_lower', 'tick_upper',
               'net_pnl', 'total_return_pct', 'sharpe']].head())

# 5. Visualize best strategy
best_idx = summary.index[0]
fig = amm.plot_performance(result, strategy_idx=best_idx)
fig.update_layout(title=f"Best Strategy Performance (idx={best_idx})")
fig.show()

# 6. Compare across parameter space
fig = amm.plot_metrics_heatmap(
    result,
    x_param='tick_upper',
    y_param='tick_lower',
    metric='sharpe'
)
fig.show()
```
