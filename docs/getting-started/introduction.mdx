# Welcome to ammBT

**ammBT** (AMM Backtesting Engine) is a high-performance, vectorized backtesting framework for testing liquidity provider strategies across multiple Automated Market Maker (AMM) protocols.

## Why ammBT?

Providing liquidity to AMMs is complex. You need to:

- Choose the right price ranges (for concentrated liquidity)
- Decide when to rebalance positions
- Balance fee earnings against impermanent loss
- Test strategies across different market conditions

**ammBT** makes this easy with:

## Supported Protocols

| Protocol | Type | Chains | Description |
|----------|------|--------|-------------|
| **Uniswap V2** | CPAMM | Ethereum, Arbitrum, Polygon | Constant product AMM with full-range liquidity |
| **Uniswap V3** | CLMM | Ethereum, Arbitrum, Polygon, Base | Concentrated liquidity with tick-based ranges |
| **Meteora DLMM** | DLMM | Solana | Dynamic liquidity with bin-based ranges and variable fees |

## Key Features

### Vectorized Strategy Testing

ammBT processes strategies in parallel using NumPy arrays. Instead of looping through each strategy sequentially, the engine:

1. Creates a position state array of shape `(n_swaps, n_strategies)`
2. Processes all swaps across all strategies simultaneously
3. Achieves O(swaps) complexity regardless of strategy count

```python
# Test 1000+ strategies in one call
strategies = create_v3_strategy_grid(
    initial_capitals=[10000, 25000, 50000],
    tick_ranges=generate_tick_ranges(num_ranges=20),
    rebalance_thresholds=[0.0, 0.05, 0.10, 0.15],
    rebalance_frequencies=[0, 100, 500],
)

result = backtester.run(swaps, strategies)  # All strategies run together
```

### Numba JIT Compilation

Critical math functions are compiled to machine code using Numba:

- Price-to-tick conversions
- Liquidity calculations
- Fee accumulation logic
- Position state updates

### Flexible Data Sources

- **Synthetic data**: Generate realistic swap sequences with configurable volatility
- **Historical data**: Load from Uniswap subgraphs, Dune Analytics, or custom sources
- **Live data**: Stream real-time swaps for paper trading

### Interactive Visualizations

Built-in Plotly charts for:

- Portfolio performance over time
- Parameter sensitivity heatmaps
- Risk-return efficient frontiers
- PnL distribution analysis

## Quick Example

```python
import ammbt as amm

# Generate synthetic swap data
swaps = amm.generate_swaps(
    n_swaps=5000,
    price_volatility=0.03,
    seed=42
)

# Define strategies to test
strategies = {
    'initial_capital': [10000, 25000, 50000],
    'tick_lower': [-200, -400, -800],
    'tick_upper': [200, 400, 800],
    'rebalance_threshold': [0.0, 0.05, 0.10],
}

# Run backtest
bt = amm.LPBacktester(amm_type='v3', fee_tier=3000)
result = bt.run(swaps, strategies)

# Analyze results
print(result.summary())

# Visualize
fig = amm.plot_performance(result, strategy_idx=0)
fig.show()
```
