# Development Setup

## Prerequisites

- Python 3.9+
- Git
- pip

## Clone Repository

```bash
git clone https://github.com/your-org/ammbt.git
cd ammbt
```

## Virtual Environment

```bash
# Create
python -m venv venv

# Activate (macOS/Linux)
source venv/bin/activate

# Activate (Windows)
venv\Scripts\activate
```

## Install Dependencies

```bash
# Development install with all extras
pip install -e ".[all,dev]"
```

## Verify Setup

```bash
# Run tests
pytest tests/

# Type checking
mypy ammbt/

# Linting
ruff check ammbt/
```

## IDE Setup

### VS Code

Recommended extensions:
- Python
- Pylance
- Black Formatter

Settings (`.vscode/settings.json`):
```json
{
    "python.formatting.provider": "black",
    "python.linting.enabled": true,
    "python.linting.mypyEnabled": true
}
```

### PyCharm

- Set interpreter to venv
- Enable Black formatter
- Enable mypy inspections

## Running Tests

```bash
# All tests
pytest tests/

# Specific file
pytest tests/test_backtester.py

# With coverage
pytest --cov=ammbt tests/
```

## Building Docs

```bash
# Install Mintlify CLI
npm i -g mintlify

# Preview docs
cd docs
mintlify dev
```
